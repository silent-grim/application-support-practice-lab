# Application Support Practice Lab

A hands-on learning repository documenting practical exercises in Application Support and IT Service Management.

## Objective

To develop and demonstrate foundational skills in application troubleshooting, incident investigation, ticket documentation, escalation, and service recovery through structured, simulated exercises.
